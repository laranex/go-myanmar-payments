# Go Myanmar Payments

[![Go Reference](https://pkg.go.dev/badge/github.com/laranex/go-myanmar-payments/v4.svg)](https://pkg.go.dev/github.com/laranex/go-myanmar-payments/v4)
[![Tests](https://img.shields.io/github/actions/workflow/status/laranex/go-myanmar-payments/tests.yml?label=tests&style=flat-square)](https://github.com/laranex/go-myanmar-payments/actions/workflows/tests.yml)
[![License](https://img.shields.io/github/license/laranex/go-myanmar-payments.svg?style=flat-square)](LICENSE.md)

A Go SDK for Myanmar payment gateways (KBZ Pay, Wave Money, AYA Payment Gateway, Yoma MMQR and CyberSource), with typed payment data, verified callbacks and a gateway-independent payment status. Built for humans and AI agents.

## Documentation

Full documentation, including installation, usage and the AI agent skill, lives at **[laranex.vercel.app/go-myanmar-payments](https://laranex.vercel.app/go-myanmar-payments)**.
